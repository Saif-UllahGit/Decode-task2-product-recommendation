# 🛍️ Decode-task2-product-recommendation

An AI-powered **Product Recommendation System** built with **Python, Streamlit, and Google Gemini API**.

This application provides personalized product recommendations based on user preferences using Generative AI. It analyzes user requirements and generates relevant product suggestions through an interactive and user-friendly Streamlit interface.

Developed as part of the **Decode Internship Program (Task 2)**.

---

## 🚀 Features

- ✅ AI-based personalized product recommendations
- ✅ Google Gemini API integration
- ✅ User preference-based suggestions
- ✅ Interactive Streamlit interface
- ✅ Natural language product search
- ✅ Fast AI-generated responses
- ✅ Clean and user-friendly UI

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Generative AI
- Python-dotenv
